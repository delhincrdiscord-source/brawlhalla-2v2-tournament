## Brawlhalla 2v2 Tournament Website — "Astonishing" Design Edition

Same solid backend as before, with the design cranked up to award-winning level.

### Stack
- **Node.js + Express**, plain frontend (no build tools)
- **Neon PostgreSQL** (`DATABASE_URL` in `.env`), `pg` driver
- **Admin auth**: password in `.env` (`ADMIN_PASSWORD`), cookie session

### Design — the "WOW" factor
A premium esportsBroadcast-style experience:
- **Animated hero**: full-viewport canvas particle storm (glowing orbs / ember sparks drifting like Brawlhalla's valhallen atmosphere) + animated aurora/gradient mesh background, huge glowing display typography with the tournament name in a metallic-gold → cyan gradient, subtle 3D floating platform silhouette
- **Custom SVG art**: a hand-crafted orbital "Legend's podium" emblem / crossed-weapons crest drawn in SVG with glow filters, animated sword shimmer on the logo
- **Micro-interactions everywhere**: magnetic glow buttons that light up on hover, tilt-on-hover 3D cards, smooth scroll-reveal animations (IntersectionObserver), animated stat counters (teams registered, slots left, prize pool)
- **Typography**: Orbitron (display) + Rajdhani (body) — authentic esports identity
- **Color story**: deep valhalla navy → cosmic purple, with radiant gold + electric cyan energy accents; glassmorphism panels with neon edge glow
- **Bracket page**: glass cards connected by animated glowing SVG lines, winner paths light up in gold as matches are reported
- **Custom cursor glow trail** on desktop, subtle screen-shake-free entrance animations
- Fully responsive & mobile-friendly

### Pages
1. **Home** — animated hero, live registration status, animated stat counters, rules/format/prizes sections with scroll reveals, Discord CTA
2. **Register** — glassmorphism two-column form (Player 1 / Player 2), floating labels, inline validation, elo inputs with number steppers, duplicate → styled error "already registered" (matched by Discord ID or in-game username across all teams), closed-registration state
3. **Bracket** — full double-elimination display: Winners bracket, Losers bracket, Grand Finals with glow lines and live winner propagation
4. **Admin** — sleek dark dashboard: Open/Close registration toggle, Generate Bracket, Remove Players (searchable list), Force Register, Report Match, teams table

### Data model (Neon Postgres)
- `teams`: both players' discord_id, username, current 2v2 elo, peak 2v2 elo, timestamps
- `settings`: registration_open flag
- `brackets`: bracket JSON state
- Duplicate prevention: reject if either Discord ID or username already exists on any team (case-insensitive)

### Double elimination (`lib/bracket.js`)
- Serpentine seeding by average current elo, byes handled automatically, WB→LB drop structure, Grand Final + bracket reset if LB champion wins first set
